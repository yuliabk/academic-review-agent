# Academic Peer Review & Revision

A reusable skill for scientific manuscripts of any discipline.

## Inputs
- Current manuscript, revision files and decision letter
- Reviewer comments, editor instructions, figures and supporting information
- Source data and current journal requirements where available

## Workflow
1. Inventory sources, manuscript versions and missing materials.
2. Audit scientific reasoning, experimental design, statistics, controls, reproducibility, figures, references and limitations.
3. Convert every reviewer concern into an independently traceable issue in the reviewer matrix.
4. Evaluate proportionate resolutions: explain existing evidence, analyze available data, revise text, propose a focused experiment only if essential, or provide a respectful evidence-based rebuttal.
5. Draft precise replacements in academic English with source-backed justifications.
6. Compose individual point-by-point responses and link every response to the matching verified manuscript change.
7. Compare manuscript, responses, figures, supplementary information, citations and document versions.
8. Prepare clean and marked files where tools allow and run submission readiness checks.

## Scientific quality controls
- Distinguish observations, interpretations and proposed mechanisms.
- Verify numbers, citations, controls, references and file edits with the primary material.
- Treat missing evidence as unresolved; do not invent data, statistics, line numbers or journal requirements.
- Prefer the least burdensome scientifically defensible remedy rather than automatically requesting experiments.
- Keep manuscripts separated by project; preserve original inputs.
- Obtain explicit user authorization for external sharing or journal submission.

## Outputs
- Short scientific audit with severity and evidence
- Atomic reviewer matrix, issue-by-issue action plan, and status report
- Exact manuscript edits and reviewer reply text
- Cross-document audit, unresolved issue list, submission gate verdict

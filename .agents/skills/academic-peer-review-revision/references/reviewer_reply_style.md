# Reviewer response patterns
For each distinct issue use:
**Comment R#.## (verbatim):** [actual text]
**Assessment:** What is scientifically at stake, what is presently substantiated.
**Action:** existing evidence / re-analysis / exact text edit / experiment / justified rebuttal.
**Response (submission-ready English):** "We thank the reviewer for this observation. [Direct answer and evidence]. [Specific change, verified location]. [Limitation where needed]."
**Evidence/source:** [dataset/figure/section]
**Verification:** applied and checked / proposed / unresolved.

Avoid "fully proven", generic "done", apologies without substantive answer, invented line numbers, and references to controls not performed. If a suggested experiment cannot be done, explain meaningful limitation without disguising missing evidence. Keep reviewer tone respectful even when disagreeing.
